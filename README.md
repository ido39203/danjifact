# 단지팩트 (가칭)

아파트 거주 후기를 붙여넣으면 AI가 항목별(주차·관리비·교통·소음·관리 상태·생활 편의)로 나누고, 주차와 관리비는 공공데이터와 비교해 후기가 데이터와 맞는지 보여 주는 웹서비스입니다. AI 바이브코딩 미니 웹서비스 과제로 만들었습니다.

- 배포 주소: (배포 후 적기)
- 시연 지역: 서울특별시 노원구 224개 단지

## 핵심 기능

1. 단지 검색 및 지도: 단지명·주소 검색, 카카오맵 위치 표시
2. 후기 붙여넣기 및 보관함: 20~1,000자, 동·호수·전화번호·이메일을 가린 뒤 이 브라우저(localStorage)에만 저장
3. AI 후기 분석: 6개 항목의 언급 여부·평가·근거 문장(원문과 대조)
4. 후기-데이터 팩트체크: 같은 구 단지 중 상위·하위 1/3 기준으로 일치·엇갈림·판단 보류·데이터 없음 판정

## 실행 방법

1. `index.html`을 브라우저로 엽니다(배포 주소로 열어도 됩니다).
2. 오른쪽 위 '키 설정'에서 카카오 JavaScript 키와 AI API 키(Gemini 또는 Claude)를 넣습니다. 키는 이 브라우저에서 해당 서비스로만 보내며, 저장을 체크하지 않으면 새로고침 때 지워집니다.
3. 단지를 고른 뒤 '시연용 후기 불러오기'를 누르면 미리 분석해 둔 예문으로 팩트체크 화면을 볼 수 있습니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면·스타일·코드(순수 JavaScript) |
| `data.js` | 노원구 단지 데이터(공공데이터를 한 번 변환해 저장) |
| `demo.js` | 시연용 예문 6건과 AI 분석 결과. 실제 거주자 후기가 아니라 시연을 위해 직접 쓴 글 |

## 데이터 출처

- 공공데이터포털, 국토교통부 공동주택 기본 정보제공 서비스(기본·상세 정보조회)
- 공공데이터포털, K-apt 공동주택 단지 관리비 정보·단지 면적 정보(2026년 1~8월 자료)
- 카카오맵 JavaScript API(지도, 주소 → 좌표 변환)

관리비는 ㎡당 단가로 비교하며, 평형별 금액은 단가 × 면적으로 계산한 추정값입니다.
